\begin{abstract}
Elliptic Curve Digital Signature Algorithm (ECDSA) stands as a cornerstone in modern cryptographic systems, offering secure and efficient digital signatures with relatively short key sizes. This report provides broad overview of ECDSA, covering its history, applications, underlying principles, procedural outline, potential attacks against it as well as some security concerns. Through this analysis, the report aims to provide the readers with a basic understanding of ECDSA and its significance in our long digitalized world of already high but steadily increasing security requirements.
\end{abstract}
