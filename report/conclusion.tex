\section{Conclusion}
The ECDSA is a very powerful tool in cryptography. The digital signature allows for a sender of a message to be verified, for example for cryptocurrency transactions or for web applications. With ECC this can be performed even with low computational power and smaller key lengths are required for the same level of security achieved with RSA. Still, its math is relatively more complicated and a lot of care should be taken when implementing eliptic curves. If not implemented correctly, this results in security flaws that compromises the authenticity of the sender. However if proper care is taken and time is spent on understanding ECC, ECDSA is a great choice for digital signatures.
